# Нотатки

Feature-гілка використовується для окремої розробки змін.
Merge об'єднує зміни з різних гілок.
Rebase переносить коміти на нову основу.
Під час роботи над feature-гілкою можна отримати конфлікт, якщо змінено один рядок.
Pull Request використовується для обговорення та внесення змін у main.
